# Локальные данные

CSV и тексты задач не распространяются. Для точного повторения эксперимента требуется исходный корпус и та же таксономия; автоматической публичной загрузки нет.

Положите разрешённые к использованию исходники в `data/raw/`:
- `tasks.csv`: поля строго в порядке `id,task,answer,topics_id,text_of_solution`;
- `topics.csv`: минимум `id,name,parent`; корень имеет пустого родителя или `0`.

Идентификаторы тем — числовые строки. `topics_id` принимает JSON-массив либо список с разделителями. UTF-8, запятые, стандартное CSV-экранирование многострочного текста.

Нормализатор создаёт `tasks_normalized_v2.csv`, `task_topic_links_v2.csv`, `manual_review_queue_v2.csv` и локальные отчёты в новом выбранном каталоге. Отчёты нормализации содержат примеры исходного текста, поэтому также не включены в Git. Не запускайте нормализатор поверх результатов ручной проверки: он обновляет файлы v2.

Можно сразу предоставить три готовых нормализованных CSV в `data/normalized/`. Минимальные поля задач: `id,task,semantic_group_id,split,target_topic_ids,subject_ids,unknown_topic_ids`; списки — JSON-массивы строк, `split` — train/validation/test. Связи содержат `topic_path_ids,topic_path_names`. Очередь содержит `id` (либо `task_id`) и `semantic_group_id`; пустая очередь должна иметь заголовок.

Команды подготовки приведены в основном README. Исходники читаются без изменения. Собственный корпус даст другие размеры, словарь и метрики.

## Версия и проверенные объёмы

Актуальная поставка — v2: 40 020 задач и 39 776 семантических групп. Подробная безопасная сводка находится в [normalization_v2_summary.json](../reports/normalization_v2_summary.json). Финальные хэши CSV совпадают с обучающим манифестом [dataset_summary.json](../reports/dataset_summary.json); это один корпус на разных этапах подготовки.

`review_group_id` обозначает группу одинакового текста для ручной проверки (100 групп, 200 задач). `semantic_group_id` учитывает также допустимые числовые варианты (98 групп, затронутых очередью). `prepare` исключает все задачи затронутых семантических групп — 205, а не только 200 строк очереди. Метки автоматически не исправлялись. В исходной разметке нет cross-subject случаев по ID или одинаковому нормализованному тексту.

`analysis_report_v2.md` содержит примеры задач, поэтому целиком не опубликован. `verification_v2.json` содержит локальные пути; в публичную сводку перенесены результаты проверок и хэши с именами файлов без путей. Числовая эвристика применяется только к достаточно длинному обычному тексту без формул, HTML и ссылок; её границы описаны в основном README и коде нормализатора.
